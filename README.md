# SUMLINE v1.3

行と列の残り合計をすべて0にする数字選択パズルです。画面・音・盤面生成はHTML/CSS/JavaScriptで動き、オンライン記録には任意の共有APIを接続できます。

## VSCodeから起動

Node.js 24以上を用意し、`package.json`がある`SUMLINE`フォルダーをVSCodeで開いてください。「ターミナル → 新しいターミナル」で実行します。

```sh
npm run dev
```

表示された`http://localhost:8000/`をブラウザーで開けば遊べます。フロントエンド用の追加パッケージのインストールは不要です。終了はCtrl+C。ソース変更後は停止して同じコマンドで再起動し、ブラウザーを更新してください。

8000番が使用中の場合：

```sh
npm run dev -- --port 8001
```

## 遊び方

- 1〜9の数字を選んで、上と左の残り合計を0にします。対象外マスの確定で1ライフを失い、3回でゲームオーバー。
- PCの標準は1回目でハイライト、同じマスの2回目で確定。設定で1回クリック式に変更できます。
- Shift＋クリック、右クリック、Fキーでフラグ設置／解除。モバイルでは単タップでフラグ、ダブルタップで選択します。
- モバイルではフラグ付きマスもダブルタップで解除して選択できます。PCではフラグを解除してから確定します。フラグ操作はライフや合計を変えません。
- カスタムでは行数、列数、文字列シード、ロックマス数を指定できます。空欄は自動、0個にも対応。指定個数で一意解を生成できない場合は理由を表示します。
- 通常・デイリー・カスタムの3モードは端末内で遊べます。ランキングと大会共有はAPI設定後に利用できます。

## オンラインID

共有APIを設定し、設定画面の「オンラインIDを作成・接続」を押すと、そのブラウザー専用のIDを作成します。秘密トークンはブラウザーに保存し、サーバーにはハッシュのみ保存します。認証はこの専用IDに統一されています。

別のブラウザーや端末では別IDになります。保存データを消した場合のアカウント回復や、複数端末でのID統合はありません。ランキング提供は初期状態でオフ。途中でオフラインになった挑戦は復帰後も送信しません。

## GitHub Pagesと共有API

GitHub公開用ワークフローを同梱しています。リポジトリのSettings → Pages → SourceをGitHub Actionsに設定し、`main`または`master`へpushしてください。ゲームだけなら共有APIを設定せずに公開できます。

ランキングと大会共有のAPIは`backend/`にあります。Cloudflare Workers＋D1への配備、許可Origin、`pages.config.json`の設定は[公開ガイド](docs/GITHUB_PAGES.md)にまとめています。

## 開発・検証

```sh
npm test
npm run build:pages
```

生成される`pages-dist/`だけをWeb公開します。ソース、テスト、バックエンド設定を静的公開ファイルへ混ぜません。GitHub Pagesのリポジトリ配下URLにも対応しています。

| ファイル | 役割 |
| --- | --- |
| public/app.js | 画面、入力、タイマー、設定、音、フラグ |
| public/engine.js | 一意解の生成、ゲーム判定、スコア |
| public/runtime.js | 接続設定と共有URL |
| public/sw.js | 静的ファイルのオフラインキャッシュ |
| lib/api.js | ランキング、大会、解答検証 |
| backend/index.js | 専用オンラインIDとAPIの入口 |
| scripts/dev-server.mjs | ローカルHTTPサーバー |
| .github/workflows/pages.yml | テストとGitHub Pages公開 |

[構成と通信先](docs/ARCHITECTURE.md)も参照してください。


## モバイル操作とレスポンシブ表示

- シングルタップでフラグ設置／解除、同じマスのダブルタップで選択します。
- シングルタップはダブルタップとの区別のため、約320ms後に反映されます。ダブルタップでは途中のフラグ切り替えを行いません。
- 画面の幅に合わせて盤面、メニュー、設定、フォームを調整します。大きな盤面ではマスの大きさを維持し、盤面の中だけを左右にスクロールできます。
- 設定の入力モードは標準で「自動」。タッチ画面にはタッチ操作、マウスにはPC操作を適用します。必要なら「タッチ操作」「PC操作」を固定できます。
- PCの1回／2回クリック設定はPC操作に適用します。タッチ操作の単タップ／ダブルタップには影響しません。

スマートフォンからローカル起動中のゲームへアクセスする方法は[モバイル対応ガイド](docs/MOBILE.md)を参照してください。
