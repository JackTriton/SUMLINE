# SUMLINE 数字選択パズル 仕様 v1.3

作成日：2026年11月6日。既存v1の数字選択ルールを継承し、今回指定された機能と初版の実装方針を整理する。以下の数式、標準値、ランキングの重複排除、期間境界は実装上の提案として採用する。

## 1. 基本ルール

N行M列、数字1〜9。正解マスを選んで左の行合計と上の列合計をすべて0にする。正解は行列双方から差し引き、対象外の確定でライフを1失う。3ライフ。初期選択済みマスは固定し、その数字は開始時点で差し引く。生成時の解探索によって一意解を保証する。

選択方式の標準は2回クリック。1回目でハイライト、同じマスの次のクリックで確定し、時間制限はない。別の場所をクリックするとハイライトを解除する。設定で1回クリック確定へ変更できる。長押しは数字と対応行列をハイライトする確認操作とし、長押し終了時に確定しない。誤ったマスは×表示して再操作できなくする。

モバイルのタッチ操作では、単タップでフラグ設置／解除、ダブルタップで選択する。ダブルタップでは既存のフラグを解除して選択できる。単タップの判定待ち、長押し、スクロールによる操作キャンセルの詳細はMOBILE.mdに定める。

## 2. モード

| モード | 盤面 | 進行・履歴 | ランキング |
| --- | --- | --- | --- |
| 通常 | 全プレイヤー共通のステージ番号に対応するシード | クリアで次のステージを解放。過去の盤面を再挑戦可能 | 初回挑戦のクリアを全体ランキングへ |
| デイリーチャレンジ | 日本時間の日付から固定する共通3盤面 | 当日の3盤面を順番に遊ぶ。日付が変われば新コース | 初回挑戦のクリアを全体ランキングへ |
| カスタム | N、M、文字列シードを指定。空欄は自動シード | 同じ設定・シード・生成器バージョンなら同じ盤面 | 全体ランキング対象外。端末内の履歴のみ |
| 大会 | 作成者のサイズ・シード・盤面数による固定コース | 開催中だけ記録可能。開催前は待機、終了後は結果閲覧 | 大会専用ランキング。全体ランキングにも通常・デイリーと区分して表示可能 |

初版では全体ランキングは通常とデイリーを集計し、大会は独立したランキングとする。条件の異なる大会を通常の進捗に加算しない。画面上で集計対象を明示する。

盤面サイズは3〜8行・3〜8列。通常は4〜6を段階的に使い、デイリーは5×5。カスタムと大会作成ではサイズを指定できる。デイリーの過去日付への提出はサーバー側でも拒否する。通常の解放は端末履歴とオンラインのクリア済み番号から復元する。オフラインで先へ進んだ後も、次の新しい盤面からオンライン記録に参加できる。サーバーは通常ステージの生成条件・クリア操作を検証し、端末内の解放順序は競技上の証明として扱わない。

## 3. スコア

未確定の必要マス数をK、盤面サイズをN×M、プレイ時間を秒単位t、残りライフをLとする。

```
基礎点 = 100 × N × M + 50 × K
速度点 = floor(3000 × (N×M/25) / (1 + t/60))
ライフ点 = 250 × L
クリアスコア = 基礎点 + 速度点 + ライフ点
```

クリア時のみ確定スコアを与える。ミスによる減点はライフ点に反映する。カスタム・再挑戦でも端末内の参考スコアを表示するが、ランキングには送らない。同じ盤面を繰り返して進捗数やスコアを増やせないようにする。

オンラインの順位用tは開始から終了までのサーバー経過時間とする。一時停止・タブ非表示も含む。ローカルのプレイ時間は停止時間を除く。両者を結果画面で区別し、速度点はランキング参加中なら順位用時間、練習ならプレイ時間から計算する。

## 4. ランキング

### 表示と順位

ユーザー名、クリア盤面数、合計スコア、1盤面あたりの平均クリア時間を表示する。各ユーザーの詳細では盤面ごとのクリア時間とスコアを表示する。順位はクリア盤面数の多い順、次に合計所要時間の短い順、最後に集計スコアの多い順とする。異なる盤面を解いた場合の完全な競技公平性は保証しないため、同条件の速度比較には大会ランキングを使う。

同一ユーザー・同一モード・同一コース・同一盤面の記録は最大1件。再挑戦は練習とする。最初の挑戦で敗北した盤面も、その後の再挑戦は練習扱いにし、正解を覚えた後のタイムを初回成績と混ぜない。

### 集計期間

| 期間 | 境界 |
| --- | --- |
| サービス開始時から | 保存済みの全対象記録 |
| マンスリー | 日本時間の当月1日00:00以降 |
| ウィークリー | 日本時間の当週月曜00:00以降 |
| デイリー | 日本時間の当日00:00以降 |

保存はUTCの時刻。記録がサーバーに受理された時点の期間に集計する。平均時間は対象盤面の時間合計÷クリア数で算出し、平均値同士を平均しない。

### 同意・オフライン

ランキング提供は初期状態でオフ。オンにしたうえでオンライン開始した初回挑戦のみ送信候補とする。途中でオフラインになった場合、その挑戦は復帰しても対象外。途中で提供設定をオフにした場合も同様。失敗した送信をキューに積まず、復帰後に遡って送信しない。ローカルのクリア履歴・解放は保持する。

ランキング送信には認証済みのユーザーIDを使い、表示名は自由入力とする。表示名からユーザーを特定しない。他人と同じ表示名でも別のIDとして扱う。オンラインID未接続でも練習可能で、ランキング参加・大会作成時には専用IDの作成・接続を案内する。

## 5. 大会の作成と共有

カスタム画面に「大会を作成」を配置する。大会名、サイズ、シード、盤面数（1〜50）、開始日時、終了日時を入力する。日付欄は日本時間として扱い、UTCに変換して保存する。終了は開始より後、最大開催期間は90日。日時と大会の状態はサーバー時刻で判定する。

作成後、大会ID付きの共有URLと大会ランキングURLを発行する。URLを開くと大会名、開催期間、サイズ、盤面数、参加状態を表示する。コースの盤面は大会ID・シード・ステージ番号・生成器バージョンで固定する。開催前はプレイ開始不可、終了後は記録受付不可。開催中に開始しても、提出時点が終了後なら受け付けない。

初版は作成後の条件変更・削除を提供しない。既存記録と条件が食い違う問題を避けるため、新しい条件の大会は別大会として作る。大会作成そのものは、プレイ前に問題の正解を作成者へ開示しない。ただしシード生成は公開実装のため、解析への完全な耐性はない。

フロントエンドはGitHub Pagesや任意の静的Webサーバーへ公開する。大会の参加者は同じ共有APIを設定したゲームへアクセスする。公開先の閲覧範囲は運営者が設定し、ゲーム内の大会作成で変更しない。

## 6. 設定・カスタマイズ

| 設定 | 内容 |
| --- | --- |
| 選択方式 | 2回クリック／1回クリック |
| 長押し | ハイライトのオン／オフ。標準450ms。離しても確定しない |
| タイマー | プレイ時間の表示、追加のRTA用カウントアップ表示 |
| RTA時計 | 開始からの実経過。停止中も進む。オンライン順位用時間に近い参考表示 |
| BGM | オン／オフ、音量。ユーザー操作後に再生開始 |
| SE | オン／オフ、音量。正解・ミス・クリアを区別 |
| ユーザー名 | 1〜24文字。HTMLとして解釈しない |
| ランキング提供 | 明示的なオン／オフ。設定変更は過去記録を自動送信しない |
| クオリティ | 高／標準／省電力。影・動き・背景効果を調整 |
| スキン | 標準のライト、ダーク、ミント。カスタム色を保存・入出力可能 |

カスタムスキンはJSONの色設定で実装する。背景、面、文字、アクセント、確定色、ミス色を定義し、`#RRGGBB`形式だけを許可する。CSS・JavaScript・外部URLの取り込みは行わない。読み込み時はサイズと形式を検証し、入力された文字列をHTMLに挿入しない。最低限のコントラストを満たさない色は拒否する。

設定と通常のプレイ履歴は端末に保存する。オンラインの通常解放・大会記録は認証IDに紐付けてサーバー側にも保持する。ブラウザー保存が利用できない場合は、その旨を画面に表示してセッション内で遊べるようにする。

## 7. 実装構成

ゲーム画面・設定・音・スキンはHTML/CSS/JavaScript。純粋関数のゲームエンジンをブラウザーとサーバーで共用する。盤面生成はブラウザーのWorker、ランキング・大会・提出検証はサーバーAPI、永続データはSQLデータベースで保持する。

オンラインAPIはBearerトークンをDBで照合してユーザーIDを決定し、クライアントが送るIDを信用しない。大会作成・セッション開始・記録提出は許可リストに登録されたOriginからの操作だけを受け付ける。サイズ・シード・日時・表示名・入力履歴件数を検証する。

記録提出時はサーバー保存の盤面と正解からクリック履歴を再生し、ライフ、正解数、クリア状態を確認する。点数やクリア数、所要時間をクライアントの申告だけで保存しない。開始時刻・提出時刻・一度限りのセッション・重複制約を使って二重加算を防ぐ。

これはカジュアルなランキングの検証であり、自動ソルバーや改変ブラウザーを完全に排除する競技基盤ではない。賞金付き大会などへの転用時は、監査・対戦監督・レート制限・不正検知の強化が必要。

## 8. 初版の確認項目

- 同一シードの再現、一意解、3×5・5×3、初期ヒントの合計反映。
- 2回／1回クリック、長押し後のクリック抑止、スクロール時の誤確定防止。
- 3ライフ、終了後の入力停止、停止とRTA時間の違い。
- 通常の解放・過去盤面の再挑戦、当日固定のデイリー、カスタムのランキング除外。
- 大会作成・共有・開始前／開催中／終了後のサーバー判定。
- 全期間・月・月曜始まりの週・日の境界、ユーザーの盤面別記録。
- 認証なし・別ユーザーID偽装・不正な提出・セッション再送の拒否。
- オフライン途中移行・送信失敗時の送信破棄、提供設定オフによる送信停止。
- 設定保存、音量、スキンの入出力、危険なスキンと読めない配色の拒否。

資料作成後、まず遊べる4モードと設定を実装し、次にオンラインAPIと永続化、最後にブラウザーと自動検証を行って公開する。残る制約や未検証事項は提供時に明記する。
