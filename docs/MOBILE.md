# SUMLINE v1.3 モバイル対応

## 操作

| 入力 | 動作 |
| --- | --- |
| 単タップ | フラグ設置／解除 |
| 同じマスをダブルタップ | そのマスを1回だけ選択・判定 |
| フラグ付きマスをダブルタップ | フラグを解除し、そのマスを選択・判定 |
| 長押し | 設定がオンならハイライト。離したときに選択・フラグ切り替えをしない |
| 指を滑らせる | スクロール。選択・フラグ操作にしない |

単タップは約320ms待ってから反映します。この間に同じマスへの2回目のタップが始まれば、最初のフラグ操作を取り消して選択します。2回目のタップの途中でフラグ表示が変わることはありません。

別のマスへのタップは別々の単タップです。固定済みマスにはフラグを付けません。一時停止、画面移動、マルチタッチ、スクロールへの移行では待機中の操作をキャンセルし、停止後や次の盤面で遅れてフラグが付くことを防ぎます。

設定の入力モードは自動が標準です。端末名や画面幅による判定だけに依存せず、実際のタッチ／マウス入力を使い分けます。タッチ対応PCでマウスを使う場合は、従来のPC操作で遊べます。入力モードを手動で固定することもできます。

## レイアウト

- スマートフォン・タブレットの幅に合わせ、メニューを画面下へ配置します。
- ホームインジケーター、画面の切り欠きなどの余白を考慮します。
- 画面内に収まる盤面は中央へ配置します。
- 大きな盤面はタップできるマスの大きさを維持し、盤面内を横スクロールできます。行の残り合計は左側に固定します。
- ページ全体、設定フォーム、モーダルを画面幅へ収め、ランキング表は必要な部分だけ横スクロールにします。
- フォーム文字と操作ボタンをモバイル向けに大きくします。
- 画面拡大の利用を妨げる最大倍率の制限は設けません。

## VSCodeで起動

PC内で試す場合は通常どおりです。

```sh
npm run dev
```

ブラウザーで`http://localhost:8000/`を開きます。PCのブラウザーでスマートフォン幅を確認するときは、開発者ツールの端末表示を使ってください。マウスでタップ動作も試す場合は、ゲーム設定の入力モードを「タッチ操作」にします。

## 実際のスマートフォンから試す

PCとスマートフォンを同じWi-Fiへ接続し、VSCodeのターミナルで起動します。

```sh
npm run dev -- --host 0.0.0.0
```

スマートフォンのブラウザーでは`localhost`ではなく、PCのネットワーク設定に表示されるLAN内のIPアドレスと8000番ポートを使います。例：`http://192.168.1.10:8000/`。実際のアドレスに置き換えてください。

この起動方法は同じネットワークからの接続を受け付けます。必要に応じてPCのファイアウォールの許可を確認し、終了はCtrl+Cで行います。通常の`npm run dev`はPC内のループバック接続だけを受け付けます。

LAN内のHTTPアクセスでは、ブラウザーによってオフラインキャッシュが利用できない場合があります。ゲーム本体とシード生成は利用できるようにし、公開時のオフライン機能はHTTPSで確認してください。オンラインランキングや大会は別途APIの設定が必要です。

## 確認範囲

- タップ判定の自動テスト：単タップ、ダブルタップ、2回目の指の保持、異なるマス、遅いタップ、キャンセル、スクロール判定、タッチ／マウス切り替え。
- ブラウザーの320・390・768・1024px幅で、盤面と設定フォームの横はみ出しを検査。
- 8×8盤面で44pxのマス、盤面内の横スクロール、行合計の固定を確認。
- デスクトップブラウザーのタッチ操作モードでフラグ設置・解除、ダブルタップ選択、フラグ付きマスの選択を確認。

iPhone・Android端末での実機検証は未実施です。対象端末・ブラウザーで公開前の操作確認を行ってください。
