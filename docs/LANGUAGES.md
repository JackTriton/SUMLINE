# 日本語・英語対応（v1.4）

画面上部の言語メニュー、または「設定 → 表示言語」から「日本語」「English」「端末の言語に合わせる」を選択できます。設定はこのサイトのブラウザーに保存され、再読み込み後も維持されます。従来の設定・進行状況・スキン・オンラインIDはそのまま引き継ぎます。

初期値は自動です。ブラウザーの最優先言語が日本語なら日本語、それ以外は英語になります。手動指定した言語は端末の言語より優先します。自動設定で端末の言語を変えた場合は、ページを再読み込みすると反映されます。

## 対応範囲

- 通常・デイリー・カスタム・大会・ランキング・設定
- 開始・中断・クリア・ゲームオーバー・記録送信状態
- 遊び方、PC／タッチ操作案内、フラグ、タイマー
- 大会作成フォーム、日付、ランキング期間、スキン関連の操作
- トースト、確認ダイアログ、API／盤面生成の既知エラー
- 読み上げ用ラベル、ページタイトル、概要
- 公開用ビルドとオフラインキャッシュ

ユーザー名、大会名、シードなどの入力内容は翻訳しません。言語変更で盤面・正解・ライフ・スコア・計測状態は変わりません。カスタムフォームの未送信入力も維持します。

大会の日時入力・表示、デイリー更新、週間／月間／日間ランキングの集計は、どちらの言語でも日本時間（JST / UTC+9）です。表示言語によって大会の開催時刻をずらしません。

## 実装

`public/i18n.js` が言語選択・パラメーター展開・既存エラーの表示変換を担当し、`public/messages.js` に英語の翻訳をまとめています。日本語の原文がメッセージキーです。`t(原文, {p0: 値})` のパラメーターは英語側で順番を変更できます。HTML構造は画面側に残し、文言と分離しています。

保存済みの旧バージョンの通知や日本語APIの既知エラーも表示時に変換します。サーバーのAPI形式・DBは変更していないため、英語化のためのバックエンド再配備やマイグレーションは不要です。未知の日本語エラーは、英語表示では汎用エラー案内へ置き換えます。

外部翻訳サービスや外部フォントには接続せず、翻訳データを静的ファイルとして同梱します。新しい文言を追加した際は翻訳カタログとテストも更新してください。

## 更新

v1.4のファイルを上書きしてGitHubへpushしてください。Pages公開ワークフローの修正（Node.js 24対応Actions・Ubuntu 24.04固定）も含みます。GitHub側の Settings → Pages → Source は引き続き GitHub Actions を指定します。

共有APIを使っている場合は、既存の `pages.config.json` またはリポジトリ変数 `SUMLINE_API_BASE` の設定を保持してください。ブラウザーの保存データを消す必要はありません。

- 自動テスト54件が成功。翻訳のパラメーター一致、既知API／生成エラー、全画面・各終了状態の英語表示、言語設定の保存、旧設定の引き継ぎ、盤面・ライフ・フラグ・タイマー・入力の維持を確認。
- `npm run build:pages` が成功。翻訳モジュールを公開用出力とオフラインキャッシュに含めています。
- ブラウザーで日英切り替え、再読み込み後の言語保持、カスタム入力保持、プレイ中の盤面保持を確認。320px／390px幅のフレームで英語のゲーム画面を表示し、ページ全体の横方向のはみ出しがないことを確認。実機のモバイルブラウザーでの検証は含みません。
